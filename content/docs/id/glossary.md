| Istilah | Definisi |
|---------|----------|
| **Distributor** | Bisnis FMCG atau grosir yang memakai Lakupak Dashboard menjual ke retailer |
| **Pembeli / Retailer** | Warung, kios, atau toko kecil yang membeli via Marketplace |
| **Marketplace terkendali** | Setiap distributor punya storefront sendiri; Lakupak tidak memaksa kompetisi harga terbuka antar penjual tidak terkait |
| **Publish** | Menjadikan produk terlihat di Marketplace pembeli (Draft tetap internal) |
| **Offer** | Program diskon atau promosi terhubung ke produk katalog |
| **Fleet** | Satu rangkaian pengiriman yang mengelompokkan beberapa pesanan, kendaraan, dan driver |
| **POD** | Proof of delivery (foto konfirmasi serah terima) |
| **MOQ** | Minimum order quantity (pieces) untuk checkout |
| **B2B** | Perdagangan antar bisnis (grosir), bukan ritel konsumen |

Konteks naratif: [Tentang Lakupak](/id/docs/about/mission-and-story).
