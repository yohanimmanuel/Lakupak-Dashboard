| Istilah | Definisi |
|---------|----------|
| **Distributor** | Bisnis FMCG atau grosir yang memakai Lakupak Dashboard menjual ke retailer |
| **Pembeli / Retailer** | Warung, kios, atau toko kecil yang membeli via Marketplace |
| **Marketplace terkendali** | Setiap distributor punya storefront sendiri; Lakupak tidak memaksa kompetisi harga terbuka antar penjual tidak terkait |
| **Fondasi operasional** | Klien, katalog, pesanan, harga, dan aktivitas penjualan yang terhubung di Dashboard; pemesanan Marketplace privat dibangun di atasnya |
| **Saluran utama / segmen pasar** | Saluran pasar utama pembeli (misalnya modern trade atau traditional trade); dipakai sebagai kunci harga segmen |
| **Harga segmen** | Harga jual untuk varian produk pada segmen pasar tertentu; menggantikan harga jual default bila ditetapkan |
| **Tarif klien** | Harga produk privat per retailer yang disimpan sebagai penawaran untuk pembeli itu |
| **Offer** | Tarif privat per retailer (atau program promosi) yang terhubung ke produk katalog untuk pembeli tertentu |
| **Pencocokan pembeli** | Menghubungkan prospek Marketplace dengan pembeli CRM yang sudah ada agar riwayat dan catatan tetap dalam satu hubungan komersial |
| **Publish** | Menjadikan produk terlihat di Marketplace pembeli (Draft tetap internal) |
| **Fleet** | Satu rangkaian pengiriman yang mengelompokkan beberapa pesanan, kendaraan, dan driver |
| **POD** | Proof of delivery (foto konfirmasi serah terima) |
| **MOQ** | Minimum order quantity (pieces) untuk checkout |
| **B2B** | Perdagangan antar bisnis (grosir), bukan ritel konsumen |

Konteks naratif: [Tentang Lakupak](/id/docs/about/mission-and-story).
