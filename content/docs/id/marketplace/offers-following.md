# Offers and following

## Offers

Home and dedicated **Offers** screens show active promotions from distributors you shop with.

## Following distributors

Follow favorite distributors for faster access in **My networks** and distributor detail pages.

## Reporting

Report inappropriate distributor content via the in-app report flow when available.
