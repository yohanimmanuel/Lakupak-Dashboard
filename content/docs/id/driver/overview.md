# Driver overview

**Laku Driver** helps fleet drivers execute assigned delivery routes for a distributor.

## Access model

Drivers do **not** self-register. The distributor creates driver credentials in **Dashboard → Logistics**.

## Main areas

- **Home** — today’s overview
- **Tasks** — fleet and delivery list
- **Notifications** — alerts
- **Account** — profile and logout
