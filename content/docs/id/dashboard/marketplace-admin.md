# Marketplace (admin)

This Dashboard page is **not** the buyer app — it shows how your business performs on the marketplace.

## Features

- Quick stats: published vs total products.
- **Distributor info** — storefront profile visible to buyers.
- **Performance** — views, engagement, and sales metrics.
- **Published products** list with links back to catalog.

Use the time-range selector to change reporting windows.
