**Marketplace Dashboard** (`/marketplace`) untuk distributor: performa storefront di aplikasi pembeli. Bukan aplikasi pembeli itu sendiri.

## Rentang waktu dan refresh

**Filter:** Last 7 days, Last 30 days, Last 90 days, Last year.

**Refresh** memuat ulang metrik.

## Statistik cepat

| Stat | Arti |
|------|------|
| **Published Products** | Aktif di marketplace |
| **Total Products** | Seluruh katalog |
| **Unpublished** | Draf siap publikasi |

## Profil distributor

**Distributor information** yang dilihat pembeli:

- **Buyers** dan **Followers**
- Nama perusahaan, **Marketplace URL**, telepon, email, alamat
- **Shipping options** dengan status **Available** / **Not offered**
- **Default lead time**, **Return policy**

**Edit settings** ke **Settings → Distributor Operations**.

## Metrik kinerja

### Metrik keseluruhan

| Metrik | Arti |
|--------|------|
| **Total Sales** | Pendapatan marketplace |
| **Total Views** | Tampilan produk/toko |
| **Conversion Rate** | View ke pembelian |

### Perjalanan pelanggan

Funnel: **Views** → **Added to Cart** → **Purchases**.

### Tabel kinerja produk

Kolom: **Product**, **Views**, **Cart**, **Favorites**, **Sold**, **Reviews**, **Sales**, **Conv %**.

**Sort by:** Views, Sales, Revenue.

Klik baris: **Detailed Performance Analytics**.

## Daftar produk terpublikasi

Bagian **Published Products** dengan kartu live.

| Tindakan | Fungsi |
|----------|--------|
| **Manage Products** | Ke katalog Produk |
| **View Details →** | Detail katalog |

Kosong: **No Published Products**, **Go to Products**.
