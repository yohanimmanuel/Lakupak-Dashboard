# Orders

## Orders list

View all B2B orders with map overview, summary cards, and filterable table.

## Actions

- **Refresh** — sync latest order data.
- **Archived Orders** — review archived rows; unarchive when needed.
- **Export Data** — spreadsheet export for reporting.

## Order details

Open a row to see line items, buyer info, payment and delivery status, and update fulfillment steps.
