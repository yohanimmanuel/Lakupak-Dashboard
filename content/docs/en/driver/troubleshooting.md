# Troubleshooting

| Issue | What to try |
|-------|-------------|
| Cannot log in | Confirm credentials with distributor; check API URL |
| Tasks empty | Wait for fleet assignment; pull to refresh |
| Upload failed | Check camera permissions and network |
| Status not saving | App retries offline queue; reopen order detail |

Contact your distributor operations team before reinstalling the app.
