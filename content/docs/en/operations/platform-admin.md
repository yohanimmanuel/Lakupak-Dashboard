# Platform admin

Access `/admin` with a platform admin account.

## Capabilities

- User management (dashboard, marketplace, driver sources)
- Account suspensions
- Global offers and announcements
- Search analytics and term maps
- Commission invoices

Protected by middleware and admin JWT cookie — separate from distributor login.
