| Term | Definition |
|------|------------|
| **Distributor** | FMCG or wholesale business using Lakupak Dashboard to sell to retailers |
| **Buyer / Retailer** | Warung, kiosk, or small shop that purchases via Marketplace |
| **Controlled marketplace** | Each distributor runs their own storefront; Lakupak does not force open price competition across unrelated sellers |
| **Operational foundation** | Connected clients, catalog, orders, pricing, and sales activity in Dashboard that private Marketplace ordering builds on |
| **Main channel / market segment** | The buyer's primary market channel (for example modern trade or traditional trade); used as the key for segment pricing |
| **Segment price** | Selling price for a product variant on a given market segment; overrides the default selling price when set |
| **Client rate** | Private per-retailer product price stored as an offer for that buyer |
| **Offer** | Private per-retailer rate (or promotion program) linked to catalog products for a specific buyer |
| **Buyer matching** | Linking a Marketplace prospect to an existing CRM buyer so history and records stay under one commercial relationship |
| **Publish** | Make a product visible on the buyer Marketplace (Draft stays internal) |
| **Fleet** | A delivery run grouping multiple orders, vehicle, and driver |
| **POD** | Proof of delivery (photo confirming handover) |
| **MOQ** | Minimum order quantity (pieces) required to check out |
| **B2B** | Business-to-business trade (wholesale), not consumer retail |

For narrative context, see [About Lakupak](/en/docs/about/mission-and-story).
